개인정보처리방침

시행일: 2026년 11월 13일

「기술사 답안공방」과 YouTube 채널 「답안공방 · 1분 시공기술사」의 영상 업로드 도구(답안공방 업로더)는 다음과 같이 정보를 처리합니다.

1. 수집하는 정보

웹앱은 회원가입이 없고 개인정보를 서버로 보내지 않습니다. 학습 기록은 사용자 기기의 브라우저 저장소에만 남습니다.

2. YouTube 업로드 도구

업로드 도구는 채널 운영자 본인의 Google 계정에 대해 YouTube Data API 권한(동영상 업로드, 채널 정보 읽기)만 요청합니다. 발급된 인증 토큰은 운영자의 컴퓨터에만 저장되며 제3자에게 제공하거나 다른 목적으로 사용하지 않습니다. 이 도구의 Google 사용자 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

3. 권한 철회

Google 계정 › 보안 › 타사 앱 연결에서 언제든 접근 권한을 삭제할 수 있습니다.
